# Weather App

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It allows users to check the current weather of any city and also view weather information for their current location using the browser's geolocation feature.

## Features

* Search weather by city name
* Get weather for your current location
* Displays:

  * Temperature
  * Weather condition
  * Wind speed
  * Humidity
  * Cloudiness
* Responsive design for desktop and mobile devices
* Loading indicator while fetching data
* Error handling for invalid city names and location access issues

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeather API
